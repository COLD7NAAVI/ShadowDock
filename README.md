# ShadowDock

> **Built for Everyone. Controlled by No One.**

An open-source, privacy-first messaging platform built for secure, real-time communication.

---

## Vision

ShadowDock is designed around a simple belief:

> **Privacy is a fundamental right—not a premium feature.**

Our mission is to build a modern messaging platform that gives users complete control over their communication while remaining transparent, open-source, and community-driven.

ShadowDock is developed with privacy-first engineering principles, minimal data collection, and long-term sustainability in mind.

---

## Philosophy

ShadowDock is built on five core principles:

- 🔒 Privacy by Design
- 🌍 Open Source Forever
- 👤 User Ownership
- ⚡ Secure Real-Time Communication
- 🚀 Future-Proof Architecture

We believe communication software should respect users by default—not require them to earn privacy through complicated settings.

---

## Current Status

**Project Stage:** Early Development

Current implementation includes:

- React + Vite frontend
- Express.js backend
- PostgreSQL database
- Socket.IO real-time messaging
- Typing indicators
- Persistent message storage

This project is under active development.
